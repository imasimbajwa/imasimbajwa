01 / about

About me

An Android developer who learns the concepts first, then builds with modern tools.

I focus on Kotlin and Jetpack Compose, and I care about how an app feels as much as how it is structured. My apps use MVVM with Clean Architecture, Hilt for dependency injection, and offline-first data with Room.

I learn the underlying libraries and their use cases first, then use AI coding agents to speed up implementation. I review every change and test edge cases myself on real devices.

I’m currently studying BS IT and documenting my Android journey as I grow.

  • Debugging with Logcat and device testing
02 / journey

My Android journey

From the first line of Kotlin to shipping complete apps.

1. Foundations

Kotlin fundamentals (null safety, data classes, scope functions, coroutines), Android Studio, Gradle, Git and GitHub, and Logcat debugging.

2. Jetpack Compose basics

Layouts, LazyColumn and LazyRow, state with remember, then ViewModel with StateFlow and type-safe navigation.

3. Real apps with real APIs

My first project, AS Weather (my internship), taught me REST APIs, Room caching, Hilt, WorkManager, widgets and 20+ languages. Then 5G / 4G LTE brought device APIs and a full network toolkit.

4. Backend and real-time

Sath, a chat app on Firebase with Auth, Realtime Database, FCM push notifications and QR-based chat.

5. UI/UX craft now

Animations, glass and fluid components, Material 3 Expressive, and my own reusable Compose component kit.
