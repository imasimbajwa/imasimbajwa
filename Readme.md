## Featured Projects

### 5G / 4G LTE: Network Tools
My first project as a developer. A network toolkit with an iOS-style glass UI.
- Speed test powered by Cloudflare
- 4G-only / 5G-only / LTE network mode shortcuts
- Data usage, device info, Wi-Fi info, battery, storage and RAM screens
- Real device data only, light/dark theme, 20+ languages
- **Stack:** Kotlin · Compose · Coroutines · OkHttp

### AS Weather
My internship project: a full weather app with a glassmorphism dashboard.
- 3-hourly and 5-day forecast, air quality, city management
- AR Qibla finder with 2D compass fallback
- Condition-based animated backgrounds and ambient sounds
- Home screen widget, WorkManager notifications, 20+ languages with RTL
- Offline-first: cached data shows instantly, then refreshes silently
- **Stack:** Kotlin · Compose · MVVM + Clean Architecture · Hilt · Room · Retrofit · WorkManager · CameraX · OpenWeatherMap · Nominatim

### Sath: Real-time Chat (side project)
A chat app in iOS liquid-glass style. *Sath* means "together" in Urdu and Punjabi.
- Email + Google login, username search, QR scan-to-chat
- One-to-one chat with delivered/seen ticks
- FCM push notifications via a small Node backend on Vercel
- **Stack:** Kotlin · Compose · Firebase Auth · Realtime Database · FCM · Node.js
